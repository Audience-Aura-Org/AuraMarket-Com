# Project Context: Aura Market

This document serves as the master prompt and context for the Aura Market project.

## Project Overview
Aura Market is a premium multi-vendor ecommerce platform tailored for the Cameroon market. It focuses on trust, real-time interaction, and a premium user experience.

- **Market:** Cameroon
- **Currency:** XAF
- **Roles:** Customer, Vendor, Logistics Company, Admin

## Core Features
- **Commerce:** Multi-vendor stores, Product discovery feed, Chat-to-buy commerce, Live selling (future).
- **Financial:** Wallet system, Escrow payment system, Vendor subscriptions, Featured product listings.
- **Logistics:** Logistics partner system, Shipping flows.
- **Engagement:** Referral system, Loyalty rewards, Push notifications.
- **Trust & Quality:** Vendor verification and reputation system, Fraud detection, Video product uploads.
- **Management:** Vendor analytics, Admin control for homepage banners and featured products.

## Technology Stack
- **Backend:** Node.js + Express + MongoDB
- **Web:** Next.js + TailwindCSS
- **Mobile:** React Native
- **Realtime:** Socket.io
- **Storage:** Cloudinary
- **Payment:** Flutterwave / Paystack

## Design Philosophy
- **Aesthetics:** Glassmorphism / Liquid Glass UI.
- **Typography:** Poppins Font.
- **Approach:** Mobile-first design, Premium feel.

## Architecture & Guidelines
- **Architecture:** MVC (Model-View-Controller).
- **Code Quality:** Modular, scalable, reusable, clean naming, and well-commented.
- **Development:** Step-by-step module generation. Focus on one module at a time.
